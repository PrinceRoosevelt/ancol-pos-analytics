The Friction: Masalah Klasik Belanja Wisata

Pengunjung theme park ingin membawa pulang kenangan berharga (boneka jumbo & apparel tematik). Namun, ada friksi psikologis terbesar: beban repot membawanya keliling wahana seharian.

Akibatnya, niat belanja tertunda hingga sore saat pengunjung sudah lelah dan terburu-buru pulang.
💡

The Concept: "Online tapi Offline" (O2O)

Mengubah konter fisik dari sekadar "tempat simpan stok" menjadi ruang pamer pengalaman (experiential showroom).

• Sentuh & coba sampel fisik di konter
• Scan QR -> Checkout di 4 E-Commerce
• Free Delivery langsung dikirim ke rumah
✨

Virtual Wardrobe & Pojok Live

SQLite WAL-Mode & Automated Financial Reconciliation

Python 3.11 • SQLite • 127k+ Rows
📁 database/db_config.py Zero-Cost Fast Engine 
def get_connection():
    # 1. B-Tree Storage Engine with WAL Mode
    conn = sqlite3.connect(DB_PATH, timeout=30.0)
    conn.execute("PRAGMA journal_mode = WAL;")
    conn.execute("PRAGMA synchronous = NORMAL;")
    conn.execute("PRAGMA cache_size = -64000;") # 64MB RAM Cache
    conn.execute("PRAGMA temp_store = MEMORY;")
    return conn
📁 database/queries.py MTD / YTD Aggregations 
def calculate_executive_kpis(conn, date_filter):
    # 2. Fast Query: Net Sales, ATV, UPT & SPH (Spend Per Head)
    query = """
    SELECT 
        SUM(net_sales) AS total_sales,
        COUNT(DISTINCT invoice) AS total_tx,
        SUM(qty) AS total_pcs,
        SUM(net_sales) / NULLIF(COUNT(DISTINCT invoice), 0) AS atv
    FROM sales_items WHERE date BETWEEN ? AND ?
    """
    return conn.execute(query, date_filter).fetchone()
