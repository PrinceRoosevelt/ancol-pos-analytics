# Universal Engineering & Design Master Blueprint (Anti-AI Slop)

Dokumen ini adalah acuan standar tertinggi bagi agen AI dalam merancang, menulis, dan memelihara seluruh arsitektur kode dan antarmuka (UI/UX) pada proyek ini dan proyek-proyek masa depan.

---

## 0. Protokol Pra-Koding (Vibe Coder's Law)
Setiap kali pengguna meminta pembuatan proyek baru atau fitur besar (misal: *"Buatkan aplikasi X dengan modul ini dan buatkan Mini-PRD-nya"*):
1. **Bahasa Manusiawi (Human-First Language, Anti-Robot):**
   - Output PRD, penjelasan, dan dokumentasi DILARANG menggunakan jargon teknis robotik yang kaku dan berbelit-belit.
   - Wajib menggunakan bahasa yang luwes, santai, to-the-point, dan langsung dipahami dalam 3 detik oleh pemula sekalipun tanpa kamus teknis rumit.
2. **Prinsip Micro-Modular (Anti-File Raksasa, Super Enteng):**
   - Dilarang membuat file raksasa (500–1000 baris) yang menumpuk semua logika di satu tempat.
   - Pecah komponen menjadi modul-modul kecil mandiri (maksimal 100–150 baris per file). Setiap komponen hanya fokus pada satu tugas (*single responsibility*).
3. **Wajib Rancang Mini-PRD Baku:** Agen HARUS menyajikan ringkasan 8 poin berikut sebelum menyentuh file kode apapun:
   - Ringkasan Eksekutif & Value Proposition
   - Arsitektur & Tech Stack Terpilih (100% Free-Tier & Zero Cold Start)
   - Alur Wireframe & Interactive Prototype (Fase 1 Mocking)
   - Skema Data, Indexing, Timezone (UTC) & Soft Delete (Tahan 3 Juta Baris)
   - Kontrak API & Real-time Flow (SSE/WebSocket jika relevan)
   - Desain UI/UX & State Komponen (Zinc palette, 8pt grid, 60fps motion, dark/light mode)
   - Keamanan & Otentikasi (HttpOnly cookie, CORS, Rate limiting)
   - Checklist Konfirmasi & Deep QA Audit Plan (Menunggu persetujuan user)
4. **Konfirmasi & Eksekusi Bertahap:** Tunggu persetujuan pengguna (`Lanjut / Approve`) sebelum melakukan perubahan atau pembuatan kode.
5. **Zero Assumptions:** Jika ada parameter bisnis yang belum jelas, tanyakan opsinya secara terstruktur alih-alih berasumsi sendiri.
6. **The Delivery Gate (Pre-Ship Scorecard):** Sebelum melapor bahwa fitur selesai, agen WAJIB menyajikan evaluasi mandiri 5 pilar (Anti-Slop, Human Factors, Strict Types, Data Integrity, Smoke Test). Seluruh poin harus berstatus `PASS` sebelum diserahkan.

## 0.2. Dewan 6 Pakar Senior (The Council of Senior Expert Skills)
Setiap perencanaan, Mini-PRD, dan eksekusi kode WAJIB ditinjau melalui 6 sudut pandang spesialis senior berikut:
1. **🎨 Senior Design System & Interaction Architect:**
   - Menjaga standar *High-Density Studio* (Linear/Raycast style), menolak gimmick AI slop (*zero sparkle, zero lava lamp*).
   - Mengelola token warna CSS native (`--brand-*`), hierarki 6 `@layer`, dan ergonomi sentuh minimal **44px × 44px** (Apple HIG & WCAG).
   - Mengunci motion pada akselerasi GPU 60 FPS murni (lerp, spring physics, zero layout reflow).
   - Menjamin 100% ikon berasal dari satu keluarga resmi Flat-Rounded Lucide SVG (`stroke-width: 1.75`).
2. **📊 Senior Data Analyst & Database Scalability Architect:**
   - Mengaudit skema database agar terbukti tahan hingga **skala 3.000.000 baris** tanpa *Sequential Scan*.
   - Menjamin aturan **Integer Rupiah murni** (membasmi kutukan komputasi floating-point trap).
   - Mengunci standarisasi timestamp **UTC (ISO 8601 / `TIMESTAMPTZ`)** dan kebijakan *Soft Delete* (`deleted_at`).
   - Merancang pagination berbasis cursor (`WHERE id < :cursor LIMIT 25`) dan metrik bisnis (omset, retensi, analitik).
3. **🛡️ Staff Cybersecurity & Zero-Trust Auditor:**
   - Mengharamkan token JWT di `localStorage` → Wajib **HTTP-Only, Secure, SameSite Cookie** (Anti-XSS).
   - Menerapkan CORS whitelist ketat dan Rate Limiting pada endpoint publik, auth, dan AI.
   - Memastikan parameterized queries (Anti-SQLi) dan isolasi variabel rahasia server (`.env`).
4. **⚡ Principal Backend & Cloud Infrastructure Architect (Zero Cold-Start):**
   - Menjamin endpoint asynchronous (`async def`) divalidasi skema ketat **Pydantic v2** / **Zod**.
   - Merancang arsitektur stateless (file dinamis dialirkan ke Cloudflare R2 / Supabase Storage).
   - Memilih hosting bebas jeda tidur (Vercel / Cloudflare Pages) dan connection pooling PgBouncer.
   - Mengutamakan **Server-Sent Events (SSE)** untuk streaming data satu arah alih-alih WebSocket yang berat.
5. **🕵️ Ruthless QA Automation & Chaos Engineer:**
   - Menjalankan uji *Race Condition* klik ganda super cepat (< 50ms) pada aksi checkout/pembayaran (idempotency).
   - Menjalankan *Input Fuzzing* ekstrem (string 5.000 karakter, angka negatif, payload XSS, emoji 4-byte).
   - Mendeteksi memory leak & zombie listeners (pembersihan listener keyboard dan interval saat unmount).
   - Pengujian pergantian hari jam 00:00 WIB vs UTC untuk mencegah selisih rekap harian.
6. **🎯 Lead Product Strategist & Human-First Copywriter:**
   - Menjamin Mini-PRD dan copy antarmuka ditulis dengan bahasa manusiawi yang santai, to-the-point, dan dipahami dalam 3 detik.
   - Memburu dan membasmi kata-kata klise marketing AI (*"delve"*, *"seamless"*, *"tapestry"*, *"game-changer"*, *"solusi mutakhir"*).
   - Menyederhanakan alur pengguna (*zero-friction UX*) dan memastikan setiap tombol memiliki nilai fungsi nyata.

## 0.5. Protokol Prototipe Interaktif (Wireframe First)
Sebelum menyambungkan database live atau backend kompleks:
- **Interactive UI Mocking First:** Buat komponen UI interaktif dengan data *mock* lokal di browser. Pengguna harus bisa mencoba alur klik kasir, cart checkout, dan simulasi struk langsung di layar.
- **Validasi Cepat:** Perubahan tata letak dan UX diselesaikan di tahap wireframe ini agar hemat waktu sebelum database di-wiring.

## 0.8. Autonomous Deep-Debug & Bug-Hunter Protocol
Agen wajib menjalankan audit mendalam untuk menemukan bug tersembunyi yang sering luput dari manusia:
- **Race Condition & Concurrency:** Uji klik ganda super cepat (< 50ms) pada aksi checkout/pembayaran untuk mencegah data ganda.
- **Floating-Point Currency Trap:** Dilarang menggunakan tipe `float` untuk mata uang Rupiah. Wajib menggunakan `Integer` bulat murni atau `Decimal` presisi tinggi.
- **Boundary & Malicious Fuzzing:** Uji input ekstrem (nama 5.000 karakter, angka negatif, payload XSS, emoji UTF-8 4-byte).
- **Memory Leak & Zombie Listeners:** Pastikan seluruh event listener keyboard, interval, dan koneksi SSE/WebSocket di-cleanup saat unmount.
- **Database Query Plan Audit (`EXPLAIN ANALYZE`):** Pastikan query riwayat transaksi diuji virtual pada skala 3.000.000 baris untuk menjamin tidak ada *Sequential Scan* yang lolos.
- **Timezone Drift Audit:** Pengujian transaksi pada pergantian hari jam 00:00 WIB untuk mencegah selisih rekap harian akibat perbedaan UTC vs WIB.

## 1. Filosofi Inti: Zero "AI Slop" & Pragmatisme
- **Dilarang Over-Engineering (YAGNI):** Jangan buat *factory pattern*, *abstract class*, atau *repository layer* berlapis-lapis jika aplikasi hanya membutuhkan operasi data sederhana. Tulis kode yang langsung, jelas, dan dekat dengan data (*colocation*).
- **Strict Typing Mutlak:**
  - **TypeScript:** Strict mode wajib aktif. Dilarang keras menggunakan tipe `any`, `unknown` tanpa validasi, atau type assertions (`as Type`) yang membungkam compiler.
  - **Python:** Type hints wajib pada seluruh signature fungsi/metode. Gunakan **Pydantic v2** untuk validasi skema data input dan output.
- **Minimal Dependencies:**
  - Utamakan API standar bawaan runtime/browser (contoh: `fetch`, `URL`, `Intl.NumberFormat`, `crypto`).
  - Dilarang menginstal library pihak ketiga untuk fungsionalitas sederhana yang bisa diselesaikan dengan < 15 baris kode native.
- **Penanganan Error Terstruktur:**
  - Dilarang menelan error secara diam-diam (`except: pass` atau `catch (e) {}` kosong).
  - Setiap error harus dicatat dengan konteks jelas dan mengembalikan status code HTTP yang semantik (200, 201, 400, 401, 403, 404, 422, 500).
- **Hard Gate: Kata Terlarang (Anti-AI Cliché Copywriting):**
  - Dilarang keras menggunakan kata klise AI: "delve", "seamless", "tapestry", "game-changer", "unleash", "revolutionize", "mulus dan tanpa hambatan", "menyelami", "solusi mutakhir". Wajib bahasa faktual dan to-the-point.
- **Anti-Chatty Code Comments:**
  - Dilarang menulis komentar kode sepele/cerewet (`// render button`, `// set state`). Komentar HANYA boleh ditulis untuk menjelaskan alasan keputusan mendalam (*why*), bukan *what*.

## 2. Standar Frontend: High Design Taste & Responsive
- **Anti-Generic UI & Anti-Gimmick (Menolak Tampilan AI Murahan):**
  - DILARANG membuat tampilan bergaya "AI Wrapper Landing Page" pada tools kerja (judul marketing raksasa di tengah, ikon bintang sparkle `✨`, badge mengambang berkedip, atau animasi lava lamp/cairan blur yang tidak fungsional).
  - Terapkan **Standar Studio Workspace Nyata (Linear / Raycast Style)**:
    - Layout ruang kerja berdensitas tinggi (*High-Density Studio*), misal: *Split-screen* (Konsol kontrol input di kiri, Canvas Inspector hasil di kanan).
    - Permukaan matte berwibawa (Deep Graphite / Obsidian `#0c0d0e`), border hairline 1px tajam, bukan drop-shadow tebal berlebihan.
    - Ikon kerja murni (panah `→`, terminal, copy, file) tanpa ikon bintang berkilau.
    - Keyboard-first shortcuts tertera jelas (`⌘↵`, `Tab`).
- **Tipografi Berkelas:**
  - Gunakan font modern (Geist, Inter, Plus Jakarta Sans, JetBrains Mono).
  - Terapkan skala tipografi yang konsisten dengan `tracking-tight` pada heading.
- **Dark / Light Mode Engine:**
  - Wajib mendukung pergantian tema otomatis sesuai preferensi OS tanpa kedip (*Zero FOUC*).
- **Rhythm & Grid System:**
  - Wajib berbasis kelipatan 4/8pt grid (spacing `2`, `4`, `6`, `8` / `gap-4`, `p-6`).
  - Prinsip *Mobile-First*: tampilan wajib proporsional dan berfungsi sempurna di layar HP, tablet, maupun desktop.
- **Aksesibilitas (A11y) & Ergonomi Sentuh Jari:**
  - Gunakan tag semantik (`<main>`, `<header>`, `<nav>`, `<button>`). Dilarang membuat "div-soup".
  - Area sentuh tombol interaktif/kasir wajib minimal **44px × 44px** (Apple HIG & WCAG) agar jari tidak salah pencet saat antrean sibuk.
  - Ring fokus keyboard wajib memiliki offset minimal 2px (`focus-visible:ring-2 focus-visible:ring-offset-2`).
- **Aset & Unified Icon System (Flat Rounded Standard):**
  - Wajib 1 keluarga icon pack resmi tree-shakable: **Lucide Icons** (`lucide-react`) atau **Phosphor Icons**. Dilarang mengarang path SVG liar dari internet.
  - Geometri Flat-Rounded mutlak: wajib menggunakan `stroke-linecap="round"` dan `stroke-linejoin="round"`.
  - Ketebalan garis (*stroke-width*) wajib seragam di seluruh view (1.5px atau 1.75px).
  - Dilarang mencampur ikon outline dengan ikon fill/solid secara acak pada view yang sama.
  - Media/gambar wajib format modern (WebP/SVG) dan di-lazy-load.
- **Pola Cascade Layers (@layer) & Token Derivation:**
  - Strukturkan CSS ke dalam hierarki layer eksplisit (`@layer reset, tokens, base, layout, components, utilities`) untuk mencegah perang spesifisitas (*Zero `!important` rule*).
  - Gunakan CSS Custom Properties native (`--brand-*`) dipadu fungsi `color-mix()` untuk turunan tema (*hover*, *tint*, *border*) instan di runtime tanpa dependensi library JavaScript.
  - Utamakan standar platform browser native (elemen `<dialog>`, popover API) sebelum memasang library eksternal.

## 3. Micro-Interactions & Motion Design (Smooth 60 FPS)
- **Interactive States:** Setiap tombol dan card interaktif WAJIB memiliki state yang terdefinisi:
  - `hover`: perubahan warna/kontras halus (durasi 150ms).
  - `active/pressed`: sedikit efek tekan (`scale-[0.98]` atau `translate-y-[1px]`).
  - `focus-visible`: ring fokus yang tegas untuk aksesibilitas keyboard.
  - `disabled`: opacity berkurang (`opacity-50`) dengan kursor `not-allowed`.
- **Akselerasi GPU Mutlak:**
  - Hanya animasikan properti CSS yang diproses oleh GPU: `transform` (scale, translate, rotate) dan `opacity`.
  - **DILARANG KERAS** menganimasikan properti layout: `width`, `height`, `top`, `left`, `margin`, `padding` (memicu browser layout reflow/jank).
- **Physics & Easing:**
  - Micro-interaction: durasi 100–200ms dengan `ease-out`.
  - Modal / Drawer / Alert: durasi 200–250ms dengan motion spring natural.
- **Feedback Loop:** Setiap aksi penting wajib memberikan feedback visual langsung (< 100ms: loading state pada tombol, toast notification, atau optimistic UI).
- **Component Animation Registry (Magic UI & shadcn/ui):**
  - Gunakan pola copy-paste registry mandiri dari **Magic UI (`magicui.design`)** dan **shadcn/ui** untuk micro-modular UI (`NumberTicker`, `BorderBeam`, `AnimatedList`).
  - Dilarang menumpuk efek berlebihan (anti-sirkus). Seluruh animasi wajib fungsional dan berdaya guna memperjelas status data.

## 4. Arsitektur Codebase (Struktur Fitur & State)
- **Feature-Driven Colocation:**
  Kelompokkan kode berdasarkan modul fitur:
  ```text
  src/
  ├── features/
  │   ├── [feature-name]/     # Komponen UI, hooks, queries, dan types milik fitur ini
  ├── components/ui/          # Komponen primitif umum (Button, Input, Modal, Badge, Toast)
  └── lib/                    # Helper/utility murni tanpa state (apiClient, formatRupiah)
  ```
- **Aturan State Management:**
  - **Server State:** Gunakan TanStack Query / SWR untuk data dari server (caching otomatis, deduplikasi query, revalidasi). Dilarang menyimpan data fetch di global state biasa.
  - **Local UI State:** Gunakan `useState` bawaan.
  - **Global Client State:** Jika benar-benar dibutuhkan, gunakan store ringan seperti **Zustand** (< 1KB). Hindari Redux yang over-boilerplate.
- **Standar Form:** Gunakan **React Hook Form** + validasi **Zod** dengan error message per field.

## 5. Standar Backend: Cepat, Bersih & Modular
- **Jika Menggunakan Python (FastAPI):**
  - Gunakan endpoint asynchronous (`async def`) untuk operasi I/O database.
  - Validasi request body, query params, dan response wajib menggunakan skema Pydantic v2.
  - Pisahkan layer secara pragmatis: `routers/` (HTTP handling), `schemas/` (kontrak data), `services/` (bisnis logika), `models/` (tabel database).
- **Real-Time & Streaming:**
  - Gunakan **Server-Sent Events (SSE)** untuk streaming teks AI dan notifikasi status pesanan satu arah.
  - Gunakan **WebSockets** hanya untuk data streaming dua arah dengan frekuensi tinggi (seperti streaming audio mentah).
- **Background Tasks:**
  - Proses berat (proses file audio, PDF/Excel generation, kirim email) wajib dijalankan di background agar response HTTP tetap instan (< 150ms).
- **Integritas Transaksi (ACID):**
  - Operasi yang melibatkan banyak tabel krusial WAJIB dieksekusi di dalam Database Transaction dengan rollback otomatis jika terjadi error.
- **Idempotency:**
  - Sediakan mekanisme pencegahan duplikasi aksi (idempotency key atau disable button saat proses berlangsung) agar aksi klik ganda tidak membuat data duplikat.

## 6. Standar Database, Skalabilitas & Data Lifecycle (Skala 3 Juta Baris)
- **Indexing Wajib:**
  - Setiap Foreign Key WAJIB memiliki index.
  - Kolom pencarian, status, dan pengurutan (`created_at`, `status`, `slug`, `code`) WAJIB di-index.
- **Aturan Timezone Mutlak (UTC Rule):**
  - Seluruh timestamp di database wajib disimpan dalam format **UTC (ISO 8601 / `TIMESTAMPTZ`)**. Konversi ke waktu lokal (WIB) hanya dilakukan di layer UI.
- **Kebijakan Soft Delete:**
  - Data transaksi keuangan, struk, faktur, dan user DILARANG di-hard delete (`DELETE FROM`). Wajib menggunakan kolom `deleted_at TIMESTAMPTZ NULL`.
- **Cegah N+1 Query & Pagination Wajib:**
  - Dilarang mengambil data berelasi di dalam perulangan loop (gunakan JOIN / Eager Loading).
  - Dilarang melakukan `SELECT *` tanpa batas. Setiap list data wajib menerapkan pagination berbasis cursor (`WHERE id < :cursor ORDER BY id DESC LIMIT 25`).
- **Migrasi Skema:**
  - Modifikasi skema database wajib melalui migration tool resmi (**Alembic** untuk Python, **Drizzle Kit** untuk TypeScript).
- **Connection Pooling:**
  - Gunakan connection pooler (misal: PgBouncer / Supabase pooler) untuk kompatibilitas serverless tanpa membuat database kehabisan koneksi.

## 7. Keamanan Zero-Trust & Otentikasi
- **Manajemen Sesi Aman (Anti-XSS Cookie):**
  - DILARANG menyimpan token JWT di `localStorage` atau `sessionStorage`. Wajib gunakan **HTTP-Only, Secure, SameSite Cookie**.
- **CORS & Rate Limiting:**
  - Terapkan CORS whitelist ketat dan Rate Limiting pada endpoint publik/auth/AI untuk mencegah serangan brute force dan bot abuse.
- **Isolasi Rahasia Lingkungan (Env Secrets):**
  - Bedakan variabel publik (frontend) dan variabel rahasia (backend/server only). Dilarang mengekspos API secret key ke sisi client.
- **Validasi & Sanitasi:**
  - Semua input pengguna wajib divalidasi dan disanitasi untuk mencegah XSS dan SQL Injection.

---

## 8. Optimalisasi Deployment & Free-Tier Resilient (Rp 0 Cloud)
- **Serverless & Edge Ready (Zero Cold-Start):**
  - Hindari server gratisan yang mengalami sleep (seperti Render Free). Utamakan **Vercel**, **Cloudflare Pages/Workers**, atau **Supabase**.
  - Rancang aplikasi secara stateless. Penyimpanan file dinamis wajib diarahkan ke Cloud Object Storage (Supabase Storage / Cloudflare R2 / S3), bukan ke disk server lokal.
- **Kecepatan Akses:**
  - Cache aset statis pada Edge CDN (Cloudflare / Vercel) untuk menjamin TTFB (Time to First Byte) < 100ms di seluruh wilayah target pengguna.

## 9. Workflow Hygiene, Verifikasi & Git Standard (10/10 Perfection)
- **Protokol `.env.example` Otomatis:**
  - Setiap penambahan variabel lingkungan (`.env`), agen WAJIB otomatis memperbarui `.env.example` dengan placeholder aman dan dokumentasi singkat.
- **Self-Verification Smoke Test:**
  - Sebelum agen melapor bahwa fitur selesai, wajib menjalankan verifikasi internal mandiri untuk memastikan nol *broken import* dan nol sintaks fatal.
- **Semantic Conventional Commits:**
  - Format commit wajib menggunakan standar industri (`feat:`, `fix:`, `refactor:`, `perf:`, `chore:`) dengan deskripsi manusiawi yang jelas. Dilarang pesan commit generik (*"update"*).
